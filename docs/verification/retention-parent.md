per turn. A stored, funded workspace snapshot carries parent scope, UUID horizon,
preceding snapshot identity and next-workspace hint. Prefix counters never come
from a browser and reset when advancing workspaces. No new table or free parent
storage allowance was introduced; existing pages keep their canonical format.

Coverage is explicitly live/partial, with no namespace-membership epoch. Workspaces
inserted behind the cursor can be missed until a fresh scan. No-workspace results
are explicitly non-durable and claim no replay availability or completion. Parent
preview never combines workspace budgets or grants parent-wide atomic application.

all admission and revalidation.

headers per turn, plus the existing100 Run headers/probe. Each continuation checks
its stored parent context, prior workspace epoch and all prior settings pins. Empty
context handoff and replacement funding are atomic. Candidate/applied pages remain
retained; Apply invalidates only continuations dependent on its affected workspace.
