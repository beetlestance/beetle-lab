# Admitted agent settlement evidence

[Contract](../design/lld/output-settlement.md). Private Journal022 operations implement
admitted performance source/absence settlement. Runner settlement HTTP, backend
credit/purge and whole-chain settlement qualification remain separate. Never-admitted
and export originals remain protected; they cannot borrow a retained hold's funding.

The client requires the shared opaque local drain observation and owns a settlement
carrier before RPC. Fence release refuses until the validated reply or actual failed
worker termination; rejected termination stays sticky. Worker eligibility reuses the
actual retirement, plan, files-absent progress, native receipt and cleaned reply.
It captures all nine recorded metadata charges and the genuine released disk hold.

One immediate transaction inserts the immutable4096-byte replay tombstone, purges a
fixed child-first original scope, reduces hold counters and inserts permanent replay
debt by exact deltas. Private authorization matches original/table/action/body and
counter before/after values. Nested cross-original or global mutations refuse.
Unexpected counts, residual rows, unsafe arithmetic and foreign references roll back.
Spool sentinel<=65536 is checked before aggregation, which is itself limit-bounded.
Old rows remain unchanged on migration; no replay charge is invented for them.

Permanent replay debt enters admission by subtraction even when no live hold remains.
A net-reducing funded transfer needs no fresh capacity after limits are lowered.
Offer, cancel, admission and raw accepted-row insertion cannot recreate retired work,
including UUID case variants. Retirement and settlement replay exact tombstone values
without consulting purged rows or repeating native work. Native absence is never
inferred from an ordinary missing row or a timeout.

Tests cover actual staged source result/control files and checked collection, absence,
real compiled worker commit/reopen, lost committed replies, held/rejected termination,
full/lowered logical capacity, late Offer/cancel, contradictory receipts, empty local
drain without native proof, nested mutation, FK refusal and transaction/migration
rollback. Files are real; Docker decisions and portable Linux inventory adapters are
unit seams. This is not a Linux image or whole-stack settlement qualification.
