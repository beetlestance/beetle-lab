# Published attachment transport

Public entry sendArtifact. Accepts a closed Run or export output record and its
parent-owned native read capability. One streamed range job; original result,
settlement and streamed integrity precede socket EOF. Fixed content policy comes
from contracts/artifact-download. No path from engine filenames is accepted.
Request lifetimes and route authorization belong to the calling route owner.

Checks: app/test/http/run-artifacts*.test.ts and app/test/exports/http.test.ts.
