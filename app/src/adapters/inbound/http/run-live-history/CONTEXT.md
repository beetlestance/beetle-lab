# Active history HTTP

GET uses the generated getRunLiveHistory descriptor and normal administrator
session guard. Query/body selectors are refused. One request owner with a 30 s
budget retains service originals and physical transport through close. The service
owns scope/binding validation; the common serializer keeps the existing 2 MiB and
JSON structural limits. Replies are no-store, never custody or execution outcomes.
Close drains request and service owners before shared runtime/store shutdown.
