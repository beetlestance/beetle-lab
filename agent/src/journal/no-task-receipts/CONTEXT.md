# No-task receipt persistence

Journal024 stores one immutable <=2048+512 receipt per funded rejected original.
The fixed private frame captures actual closure/intent and installed root/marker;
canonical receipt equality binds daemon/name/root/request. Existing16KiB control pays.
SQL permits are scoped to exact original/body/digest; global/other-original writes
remain isolated. Native proof is supplied only by the main-thread opaque owner.
No cleanup routing, settlement, disk-hold credit or permanent replay transfer here.
