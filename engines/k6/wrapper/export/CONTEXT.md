# Staged standalone generation

runStagedExport receives fixed image roots/installed schema and the trusted runtime
assignment digest, opens the bounded native assignment through the shared loader,
and composes shared lifecycle, compiler/build/custody, publication and control.
No k6 execution child or target collector. Dedicated export.result and file remain
separate from performance verdicts. Original work and closes drain before return;
receipt is coordination evidence, never physical container absence or disk release.
Failures without confirmed publication produce no invented terminal manifest.
