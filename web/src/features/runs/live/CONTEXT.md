# Run views

RunDetail owns scoped queries/cancellation. Nonterminal runs select live; restored/
terminal records select results. Watched runs stay live until Open result remounts.
Route/run/attempt changes remount copy.phaseOf: waiting, starting, running, cancelling, finalizing, ended.
Accepted cancellation disables the action, outranks stale reads and starts the timeline retained through Finalizing.

Early boards use plain steps, an indeterminate bar, bottom cancellation, exported
Starting art and skeleton figures. Queue reads share a scoped query; errors hide
cached holders/capacity and expose retry. Preflight needs the verified revision;
compilation needs phase.started prepare/execute, never validate.finished alone.
Steps never invent progress, initiators or elapsed time. Phone whole chart retains source geometry, hover and sampled coverage.
Ultrawide aligns the whole-run chart, thresholds and endpoints. Phone endpoint
tables pin p95 and Failed. Engine labels use one scoped status read and exact matching.

plan reads pinned stages/requests/rules/target units; rN is request index N.
target-charts normalizes fully declared groups to MB/%/ms/count; otherwise the
group stays raw with source labels. Shared target formatting preserves tiny values.
model derives one window and uses the slowest endpoint when pooled latency is absent. Unknown dimensions/values and missing/future/unparseable starts stay
explicit; they never become zero elapsed time or invalid geometry.

Feed validates Run and UUIDs case-insensitively. stream owns leases/pause/retry;
history keeps <=900 actual metric windows and <=256 recorded/live target samples.
Archive ordinals preserve duplicate UTC times, full values, phases/reasons/nulls;
live projections cannot overwrite recorded values. Detached target identity survives
omitted hints and retires on owner changes. Only producer count 256 marks its
limit; page-buffer capacity does not. Shared hover, source gaps and singleton
points remain visible. Strict recorded hover hides readings beyond coverage/gaps.
Optional per-series source coordinates retain independent observations; their
cursor uses requested time, never a fabricated union-grid reading. Stored values stay raw.
Bootstrap/coverage/lifetime rules: docs/system/contracts/active-history.md.

Namespace queries have scoped retry. After verification, one workspace snapshot
fills the passive badge; restored read-only views add no current-work polling.
Cancellation/read-only access use session context, never a new session read.
Live downloads project up to 900 retained windows as provisional TXT or CSV.
No extra read or sealed artifact publication. Script picker reads 20 summaries
plus the pinned revision; older history links to the suite. Revisions bind scope,
suite, ID and digest. Terminal attribution reads sealed sources.
