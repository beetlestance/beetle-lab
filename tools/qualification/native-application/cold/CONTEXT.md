# Packaged cold recovery qualification

Task-owned default Compose installation only. One ordinary synthetic run, then
stop every owned peer before packaged backup. Maintenance runs as UID 1000 with
explicit bounded resources and socket group; never repair source permissions.
Archive and restore live in a new private sibling under the setup-owned home.
No user installation, prune, source-data deletion or mutable restore adoption.
Preserve private outcomes and exact image/source identity. Independent review
before composed execution. This packet does not prove ENOSPC, soak or rollback.

Read-only CI cold-recovery runs only missing AMD64; ARM acceptance is reused.
cleanup.ts validates exact owner/project/revision before independent bounded
teardown, including interruption. public.ts rejects incomplete facts and emits
closed counts/identities only; raw errors/config/DB/credentials remain private.

source.ts BUNDLE OLDER_PUBLICATION_JSON NEW_OUTPUT [CONTEXT] reuses the same
executor as the published run.ts entrypoint, verifies all source images and the
older published installer/frontend pair, then adds exact foreign-resume conflict
and older historical-reader compatibility. No pull/build or mutable/in-place
rollback. Only restored history may be opened by the older pair. All owned helper
containers/networks are removed between viewers; original serving data stays cold.
Future incompatible schema rollback is not supported by a matching-schema proof.
